# metis-labs
Prototipos, MVPs y pruebas de concepto de Metis: un espacio para experimentar antes de llevar algo a producción.

## Contenido

| Carpeta | Qué es |
|---|---|
| [`mvps/`](mvps/) | Propuestas de MVP del equipo, una carpeta por MVP (`mvps/<número>-<autor>/`). Ninguna es la versión definitiva: sirven para comparar ideas antes de decidir qué pasa a producción. |
| `pocs/` | Pruebas de concepto, una carpeta por prueba (`pocs/<nombre>/`) con su propio README. |

### MVPs

| MVP | Autor | Estado | Resumen |
|---|---|---|---|
| [`01-ariel`](mvps/01-ariel/) | Ariel | Primer MVP, exploratorio | App local con Docker (API, web y PostgreSQL): currículum oficial por OA, estudiantes PIE/TEA y evaluaciones con el asistente Metis (Evalia). Viene con su historial desde la rama `metis-app-mvp` de `metis-studio`. |

Para sumar un MVP, crea `mvps/<siguiente número>-<tu nombre>/` con su propio README y agrégalo a esta tabla.

Cada carpeta es independiente: tiene su propio README, `.gitignore` y forma de levantarse.
