# metis-labs
Prototipos, MVPs y pruebas de concepto de Metis: un espacio para experimentar antes de llevar algo a producción.

## Contenido

| Carpeta | Qué es |
|---|---|
| [`mvp/`](mvp/) | MVP de Metis: app local con Docker (API, web y PostgreSQL), currículum oficial por OA y evaluaciones con el asistente Metis (Evalia). Viene con su historial desde la rama `metis-app-mvp` de `metis-studio`. |
| `pocs/` | Pruebas de concepto, una carpeta por prueba (`pocs/<nombre>/`) con su propio README. |

Cada carpeta es independiente: tiene su propio README, `.gitignore` y forma de levantarse.
